# Thomas Cup 2022 Dataset

This repository contains the datasets collected and prepared for the Thomas Cup 2022 badminton tournament.

## Contents

- Raw tournament data
- Cleaned datasets
- Data collection scripts
- Data preprocessing pipeline

## Repository Structure

- `raw_data/` – Original collected datasets
- `cleaned_data/` – Cleaned and processed datasets
- `scraper/` – Python scripts used for data collection
